# Public Kundli Generator

A lightweight Streamlit application that creates a North Indian Vedic birth chart and shows current planetary transits. This public edition has no PDF/RAG/LLM dependencies and does not maintain a saved-profile database.

## Run locally

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run kundli_public_app.py
```

## Streamlit Community Cloud

Use `kundli_public_app.py` as the app entry point.

Astrology is not scientifically validated. This application is for educational and entertainment purposes only.
